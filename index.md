# Privacy Policy

**App:** Dupe Remover
**Developer:** Mathieu Rancourt
**Last updated:** 2026-05-18

## Summary

Dupe Remover does not collect, transmit, store, share, or sell any personal information. Everything the app does happens entirely on your Mac.

## Information we collect

**None.** The app has no analytics, no telemetry, no crash reporting, no advertising SDKs, no user accounts, and no third-party services of any kind.

## Network access

Dupe Remover has **no network entitlements**. macOS prevents the app from making any internet connection — incoming or outgoing — regardless of how it is used. You can verify this in the app's signed entitlements:

- `com.apple.security.network.client` — not present
- `com.apple.security.network.server` — not present

## Files the app reads

The app is sandboxed under macOS's App Sandbox. It can only read folders you explicitly grant it access to by selecting them in the "Choose folder…" dialog. It does not access any folder you have not personally selected.

Within those folders, the app reads image files (JPEG, PNG, HEIC, TIFF, GIF, WebP, BMP) in order to compare them and group duplicates.

## Files the app writes

The only data Dupe Remover writes outside the folders you scan is a local cache stored inside the app's sandbox container, at:

```
~/Library/Containers/com.matranc.duperemover/Data/Library/Application Support/com.matranc.duperemover/cache.plist
```

The cache contains:
- File paths, sizes, and modification times of images you've already scanned
- SHA-256 hashes of those images
- Visual feature prints generated by Apple's on-device Vision framework

The cache exists so repeat scans of the same library finish in seconds instead of recomputing everything. It never leaves your Mac.

You can delete the cache at any time from the app's menu: click the three-dot icon in the toolbar → "Clear cache."

## Deletion of your photos

When you select duplicates and click "Move to Trash," the app uses the system Trash. Files are not permanently deleted — you can restore them from Trash until you empty it.

## Children's privacy

Because the app collects no information of any kind from any user, it is automatically compliant with the Children's Online Privacy Protection Act (COPPA) and similar legislation.

## Changes to this policy

If this policy ever changes, the updated version will be published at the same URL with a new "Last updated" date. Because the app does not collect data, material changes are not anticipated.
